# Slow scrape

## Error

Slow scrape

## Root Cause

Poor parallelization and inefficient file existence checking operations (`O(n)` per file exists check instead of `O(1)` list lookup).

## Fix

Use CC (Claude Code) for optimization including `headless` option. Also, instead of per file exists check `O(n)`, create a list of files available and use that directly `O(1)`.
