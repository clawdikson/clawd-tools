## Error
False drops in large numbers

## Root Cause
Issue was the usage of geo_location and radius which resulted in unsuccessful requests (false empty data) from the API. Removed this usage in the code and the code started running properly
## Debugging steps
1. Checked the logs and the outputs to see that while facet search was resulting in proper provider ids, the summary API was not returning data
2. Verified that these provider ids exist with data in the source site
3. Concluded that the error was in the summary api
4. Checked the code to find that an arbitrary network id was instead of actual provider networks
5. Also, found that we were using geo_locations. Initially checked with 1500 radius and found this resulted in better outputs.
6. Checked the Phase 2 details code for how we implemented the summary API and found that geo_location was an optional param
7. Removed this and found the fix to work properly.
