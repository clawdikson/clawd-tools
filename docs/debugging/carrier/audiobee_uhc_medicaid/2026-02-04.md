## Error
Slow scraping speed and 202 errors using page.request APIRequest for API calls

## Root Cause
Found that currently using APIRequest (page.request), which was working previously, resulting in soft bans (empty responses) along with unlimited retries

## Fix
Switched from page.request APIRequest to js evaluate which directly uses the console API for executing XHR requests along with appropriate cookies and headers. This also significantly increased the scraping speed.

## Debugging Process
1. Checked the reasons for 202 errors at the beginning
2. Used CC for refactors, warmup times, different headers, different login urls. Any didn't work - Est time used was 2hrs
3. Manually checked the request code and found that we were using APIRequest (page.request) for API calls. We know that js evaluate is better in terms of bypass compared to page.request based on usage in other sites like Anthem. Implemented the js_get and js_post methods using CC and tested this out. The code worked successfully.

## Key Takeaway
Based on the debugging process, the key lesson learned is that using native browser JavaScript evaluation can be more reliable than Playwright's APIRequest for certain sites.
