# Error

# Root Cause

Corrupt/empty files for some county + specialty combinations.

# Fix

Removal of corrupt/empty files. Addition of static sleep for navigation to complete before scraping HTML.

# Debugging Process

1. Found the providers in the UI.
2. Found that these providers have common params like they had the same county (Kennebec) + specialty (Certified Nurse Practitioners). Checked the raw files for these providers and found that the page 2 for these providers were corrupt/empty and the list in the UI had these providers in page 2.
3. Issue found to be corrupt/empty files for some combinations.
4. Fixed this by adding a constant timeout after navigation to allow the full HTML to render.
5. For old raw files with this issue, used a script to identified combinations with empty pages and deleted all the pages for these.
6. Reran the scrape.

# Key Takeaway

Implement proper pagination and wait times to avoid corrupt/empty files.
