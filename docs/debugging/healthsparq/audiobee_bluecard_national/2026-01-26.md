# Error

Providers were mapped to all networks

# Root Cause

Mapper function returned all networks if no plan codes were passed.![](https://t9017490901.p.clickup-attachments.com/t9017490901/3fff5683-0d22-43fd-9908-23294345c2bb/image.png)

# Fix

Update mapper fn in healthsparq/ and bluecard\_national/ to accept path. Post process the filenames for extra information like recovered/, \_missing and so on.

# Debugging Process

1. Found all networks to have the same provider count
1. From this information, assumed that there is an error with the mapper where networks were not mapped correctly.
1. Checked the mapper logic and found the false condition to return all networks and there was no usage of filename in the logic (bluecard needs that information)

# Key Takeaway

Document and test fixes thoroughly before applying to similar projects.
