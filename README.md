# 🛠️ ClawdBot Tools Directory

Personal productivity tools built by the Overnight Coder and on-demand.

## How It Works

1. **Backlog** → `tools/backlog.md` has tool ideas ranked by impact
2. **Overnight Coder** picks the top unbuild tool each night
3. **Built tools** go in subdirectories here with their own README
4. **Log** → `memory/overnight-builds.md` tracks what was built and when
